# web-tesis
Sistema Web de Agenda, Cotizacion y Ventas Para Servicio de limpieza a domicilio

Sistema web desarrollado como Proyecto de Titulo de la carrera de Ingenieria en Ejecucion en Computacion e Informatica (Universidad del Bio-Bio), para la microempresa de servicios de limpieza a domicilio MarcelasCleaningMn (Saint Cloud, Minnesota).

El sistema centraliza tres procesos clave del negocio, actualmente gestionados de forma manual (WhatsApp, llamadas y papel):

Agenda: administracion de disponibilidad y citas de servicio.

Cotizacion: calculo automatizado del valor de un servicio segun tipo de limpieza, tamaño del inmueble y servicios adicionales.

Ventas: registro y seguimiento de los servicios contratados e historial de clientes.
